# M06 / Artifact v1 — contract for M07/M08
Existing T09 schema opencode.task-output.v1. No new storage/service. Each manifest record contains requestId (16 lowercase hex), artifactId (32 lowercase hex), name, mime (text/plain, text/markdown, application/json only), byteSize 0..32768, sha256 lowercase 64 hex, createdAt and delivery {kind:"authenticated-route",path,expiresAt}. Scope = task/project/session/repository resolved by server; principal remains existing authorized supervisor. No private source path. Never accept /bundle or arbitrary absolute URL as a download.
GET /api/supervisor/v1/tasks/{requestId}/artifacts?limit=1..8&after={requestId}:{artifactId}; no query retains compatibility max 8; nextAfter null or task-scoped cursor, scanned counts scanned records. GET with format=text|json exports max 2 records per page, 512 KiB encoded cap; sourceSha256/sourceByteSize refer to original verified bytes, redacted text is not a byte receipt. Unbounded transcript stays disabled.
Download GET /api/supervisor/v1/tasks/{requestId}/artifacts/{artifactId}?expires={expiresAt}; expiry generation is nonsecret and mandatory, never a bearer. Legacy URL must refresh manifest. Auth stays Cloudflare Access + bearer in header; no query credential. 404 foreign/missing before expiry; 410 stale/expired same scope; 416 range unsupported; 502 integrity failure. 200 attachment, no-store/private, nosniff, same-origin, explicit length/mime and X-Artifact-SHA256. Collector independently hashes exact returned bytes and compares name/size/type/task/digest; no successful textual assertion or metadata alone. No credentials or full bytes in MCP manifest. Existing staging_task_artifacts returns manifest; M02/M08 may wire optional pagination to RPC, not changed here.
P21 client validates typed file part {type:"file",uri:delivery.path,mime,name,artifact:<record>} or bounded MCP text JSON manifest. Displays expected hash and route, no automatic request. Only save bytes after independent check, no redirects, no credentials persisted or in URL. Existing general tool file parts kept separate. Browser current cookie-only fetch will correctly get 401 if no authorized header; authenticated transport injection supported but no new broker or secret exposure.
